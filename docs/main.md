Create a HelpMe AI-first UI mockup.

This is not a dashboard app.
The app should not show many cards, stats, or lists by default.

Core philosophy:
- AI reads tasks, deadlines, goals, and calendar for the user.
- The main screen shows only the next best action.
- Details are hidden by default.
- Users can ask for context if needed.
- Full task/deadline lists live in Archive, not on the main screen.

Main screen:
- App title
- Small AI presence indicator
- AI briefing sentence
- Next best action card
- Short reason
- Three actions max:
  Start focus, Ask why, Show hidden context
- Quiet summary:
  hidden tasks count, watched deadlines count

Navigation:
- Now
- Ask
- Review
- Archive
- Settings

Style:
- Minimal
- Mostly monochrome
- No dashboard grid
- No right AI panel
- No colorful KPI cards
- No long lists by default
