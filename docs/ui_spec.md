# HelpMe UI Specification

The interface should feel calm and operational. It should be light, fast, and useful every day.

## Navigation

Navigation is hidden behind a menu:

- Now
- Today
- Inbox
- Calendar
- Deadlines
- Goals
- Habits
- Review
- Settings

The Orb is always visible and opens the AI command overlay.

## Default Experience

The app should not open with a noisy KPI dashboard. It should open with a clear next-action experience, then let the user move into Today, Inbox, Calendar, Deadline Radar, Goals, Habits, and Review when needed.

## Screen Roles

### Now

Shows the recommended next action. It may allow manual selection through Goal -> Project -> Task.

### Today

Shows a timeline, suggested focus, overload signal, and minimal day summary.

### Inbox

Shows unprocessed captured tasks and an "Organize" AI command.

### Calendar

Shows time blocks and events. Planning changes require confirmation.

### Deadlines

Groups deadlines into overdue, today, this week, and later.

### Goals

Shows goal -> project -> task relationship and progress.

### Habits

Shows routine health, streaks, completion rate, and short AI-style insight.

### Review

Supports evening reflection and proposal-based rescheduling.

## AI Command Overlay

The overlay must show:

- Suggested commands.
- User input.
- Read-only answer, or
- Proposal card with Confirm and Cancel.

Any mutation must go through a proposal card first.

## Visual Rules

- Use meaningful icons instead of long labels where possible.
- Keep text concise.
- Avoid overlapping UI and cramped cards.
- Use color only for meaning: AI recommendation, deadline pressure, confirmation.
- Keep the Orb present but not distracting.
