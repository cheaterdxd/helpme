# HelpMe MVP Scope

HelpMe is a lightweight local-first AI life admin desktop app.

The MVP focuses on UI-first development.

Core screens:
- Dashboard
- Today
- Tasks
- Deadlines
- Activity
- Settings

Core experience:
- Minimal dark UI
- AI Orb with lightweight CSS animation
- Mock data first
- No backend in the first milestone
- No real local LLM in the first milestone
- No heavy 3D, WebGL, particle systems, or complex calendar libraries

MVP features:
- Display today's tasks
- Display upcoming deadlines
- Display AI suggestions
- Display AI activity log
- Switch pages from sidebar
- AI Orb states: idle, listening, thinking, suggesting, alerting, sleeping
